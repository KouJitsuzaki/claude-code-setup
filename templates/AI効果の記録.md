# AI効果の記録の書き方

## 1. 投入時間 `docs/AI効果/投入時間.md`

セットアップや設定にかけた時間を、日付・誰が・何分・何をしたかで足していく。会社側の支援の時間も含める（本人に聞く）。

## 2. 業務の基準時間 `docs/AI効果/業務の基準時間.md`

| 業務 | AIなしだと何分か | 頻度 | 根拠（本人申告／計測） |
|---|---|---|---|

表に無い業務が出てきたら、記録する前に本人に聞いて足す。

## 3. AI活用ログ `docs/AI効果/AI活用ログ.csv`

作業や自動化のたびに1行足す。1行目（見出し）：

```
日付,業務名,区分,AIなしの見込み(分),実際にかかった時間(分),削減時間(分),見込みの根拠,楽になったこと,成果物の場所
```

- 区分：集計／転記／管理／報告／その他
- 実際にかかった時間：やり取りを始めてから成果物ができるまで
- 見込みの根拠：基準表／本人申告／推定 のどれか。盛らない。時間が増えたらマイナスのまま書く
- GAS で自動で回るものは、回った週ごとに1行（実際にかかった時間は 0、削減時間は基準時間×回数）
- お金・個人の数字・顧客名は書かない
- セットアップそのものは書かない（投入時間に入れる）

## 4. 週次レビュー `docs/AI効果/reviews/YYYYMMDD_週次レビュー.md`

先頭に必ず次の集計ブロック（項目名と順番は変えない。受け取る側が機械で読む）：

```
【集計】
種類: 週次
期間: YYYY-MM-DD〜YYYY-MM-DD
今回の削減時間(分):
累計の削減時間(分):
投入時間の合計(分):
投資対効果(倍):
件数:
楽になった業務1:
楽になった業務2:
楽になった業務3:
困っていること:
```

続けて：今週の主な作業、楽になったこと、うまくいかなかったこと、来週AIに任せてみたい業務。
最後に「地図の変更提案」：今週 `docs/地図との違い.md` に足したもの（地図の箇所／今→案／根拠）。無ければ「なし」。会社側はこれを見て地図を直す。
記録が0件の週も0件として作る（止まっていないと分かるように）。
同じものをドライブの `AI効果レポート` フォルダにも置く（Googleドキュメントではなく .md かテキストでよい）。GAS がこのフォルダから送る。
