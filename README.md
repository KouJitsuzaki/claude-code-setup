# Claude Code セットアップ（Choice group 全体版）

Choice group（choice aid をはじめ、グループの各社・各部署）のメンバーが Claude Code を仕事で使い始めるためのセットアップ一式です。
このページのURLを受け取った人は、下の **3つ** をやるだけです。あとは Claude が、あなたのパソコンと Google ドライブを**読んで**、あなた専用のルール（`CLAUDE.md`）・仕事の地図・フォルダを作ります。白紙から説明する必要はありません。Claude が作った下書きに「合っている／違う」と答えるだけです。

---

## あなたがやること（約15分）

### 1. Claude のデスクトップアプリを入れて、ログインする

- https://claude.ai/download から、パソコン（Windows か Mac）に合うものを入れる
- 自分の Claude アカウントでログインする。Claude Code を使うには **Pro 以上の有料プラン**が必要（設定 → プランで確かめられる）

### 2. Google ドライブをつなぐ

1. Claude アプリの左下のアイコン → **設定** → **コネクタ**
2. **Google Drive** の「接続」を押し、**仕事のファイルが入っている（共有されている）Google アカウント**を選んで「許可」
3. **Google Sheets** があれば、同じように接続する

### 3. 作業フォルダを作り、Claude に1文を貼る

1. 「ドキュメント」の中に、仕事用のフォルダを1つ作る（例：`仕事`）
2. Claude アプリの上の **Code** タブを開き、フォルダの選択で 1. のフォルダを選ぶ
3. 入力欄に、次の1文をそのまま貼って送る

```
次の手順でセットアップを進めてください：https://raw.githubusercontent.com/KouJitsuzaki/claude-code-setup/main/SETUP.md
```

---

## Claude がやること

1. パソコンの仕事のフォルダと Google ドライブを**読む**（ファイル名・フォルダの形・最近使ったものが中心。中身を開くのは仕事のファイルだけ）
2. 「あなたの仕事の全体像」と「仕事の地図（どのシート・フォルダで何をしているか）」の下書きを作る
3. 下書きを見せて、違う所・足りない所だけ聞く
4. あなた専用の `CLAUDE.md`（Claude が毎回読むルール）とフォルダを作る
5. 時間がかかっている手作業から、自動化の候補を出し、最初の1本を一緒に作る
6. AI で減った時間を記録し、週1回レビューを作る

## 途中で気をつけること

- Claude が「このコマンドを実行してよいか」と聞いてきたら、内容を読んで許可してください。分からなければ「これは何をするの？」と聞き返して大丈夫です。
- Claude はファイルを消しません。ドライブのファイルも読むだけで、書き換えません。パソコンのファイルを動かすときは、必ず先に計画を見せて OK を取ります。
- 写真・家計・私的なメモなど、仕事でないフォルダは開きません。見られたくないフォルダがあれば、最初に Claude に伝えてください。
- 途中でやめても大丈夫です。同じフォルダで Code タブを開き「セットアップの続きをして」と言えば、続きから始まります。

## 更新について

このリポジトリが更新されると、次に Claude を開いたときに自動で取り込まれます（作業フォルダの `.setup/` に入っています）。

## このリポジトリについて

- 公開されています。会社や個人の情報、お金の数字は入れていません。仕事の中身は、各自の権限でパソコンとドライブから読みます。
- 中身：`SETUP.md`（Claude が読む手順）、`rules/`（全員共通のルール）、`templates/`（作業フォルダに置くひな形）、`context/`（会社・部署ごとの業務の地図を置く場所。今は空）、`scripts/gas/`（週次レビューの自動メール）
